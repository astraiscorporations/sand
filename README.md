# Sand
The Sand Interpreter is the interpreter that uses Python to run and for libraries.
It is prebundled with notation and notateOS.

Sand can be used for notateOS' Frameworks and Applications.

# Installation
**1.**
	Get the latest release and download it or get the source code
	*git clone https://github.com/astraiscorporations/sand/ sand*
	Copy *sand/main/** into */usr/lib/sand/*
	*sudo cp -r sand/main/* */usr/lib/sand*
	Make a symbolic link from */usr/lib/sand/main.py* to */usr/sbin/sand*
	*ln -s /usr/lib/sand/main.py /usr/sbin/sand*
